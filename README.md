# 📦 SHAPACK — Emballages Alimentaires Personnalisés (B2B)

Site vitrine B2B multi-pages pour **SHAPACK**, conçu sur le modèle de référence de Mel'Pack avec une charte graphique épurée **Bleu & Blanc**.

## 🚀 Démarrage

```bash
npm install
npm run dev
```

Serveur disponible sur `http://localhost:5173/`

## 📄 Pages du Site

1. **Accueil (`/`)** : Promesse de valeur, 3 piliers d'offre, aperçu des gammes, étapes de commande.
2. **Nos Produits (`/produits`)** : Catalogue segmenté en 5 univers (Chaud, Salades, Boulangerie, Sacs, Gobelets).
3. **Solution de Stockage (`/stockage`)** : Explication de la prise en charge logistique et des livraisons fractionnées.
4. **Nos Réalisations (`/realisations`)** : Galerie photos de packagings réels réalisés pour des enseignes.
5. **Contact / Devis (`/contact`)** : Formulaire d'expression de besoin B2B et coordonnées directes.
